du bâtiment

Comprendre les consommations, fiabiliser les relevés et préparer les actions d’amélioration.

À propos de cette version

Ce guide est consultable immédiatement. L’archive de l’application est incomplète : les pages de l’administration et le serveur API manquent. Ce document présente une méthode ; il ne simule pas des résultats d’audit.

GUIDE PAS À PAS — SANS VIDÉO EXTERNE

Avant de démarrer

  • Définir les bâtiments et la période étudiée.
  • Rassembler les factures et identifier les compteurs.
  • Vérifier les unités et les périodes de mesure.
  • Distinguer les données mesurées des estimations.
  • Faire chiffrer et valider les actions avant de décider des travaux.
