# Origine des ressources et cadre d’utilisation

## Logiciel

Le code d'administration et les scripts SQL proviennent d'une base logicielle MyEMS préexistante. Source du projet amont : https://github.com/MyEMS/myems.

Les noms **Moustapha IBRAHIM DJAMA, Thomas DHUNARA et Mariel FRESNEL** désignent le groupe qui présente et organise ce dossier pédagogique. Ils ne remplacent pas les développeurs du logiciel et ne constituent pas une revendication de paternité du code source.

La licence MyEMS (voir `../LICENSE`) demande de conserver ses mentions de droit d'auteur et son identité de marque. Les fichiers de tiers et leurs mentions de propriété intellectuelle ne sont donc pas réattribués.

## Illustrations

Les quatre fichiers `maquette-*.png` ont été fournis dans l'archive de référence. Ils affichent une interface « ÉnerBat » et des valeurs fictives ; ils sont utilisés uniquement comme maquettes de démonstration. Aucune de ces valeurs n'est présentée comme le résultat d'un audit réalisé par le groupe.

Les deux schémas SVG sont des supports explicatifs présents dans l'archive de référence.
