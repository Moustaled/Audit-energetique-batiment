# Scripts de base de données MyEMS

Ce répertoire contient des **scripts SQL techniques issus du logiciel MyEMS**. Les noms techniques des fichiers et des dossiers sont conservés pour éviter toute ambiguïté avec la documentation amont.

- `install/` : scripts de création des bases.
- `upgrade/` : scripts historiques de migration.
- `recalculate/` : opérations de maintenance à ne jamais lancer sans sauvegarde.
- `demo-fr/` : jeu de démonstration en français fourni dans l’archive d’origine.

**Attention :** les scripts n'ont pas été exécutés ni validés dans un serveur de base de données. Ne pas les lancer sur une base existante sans disposer d'une sauvegarde et de la documentation MyEMS.
