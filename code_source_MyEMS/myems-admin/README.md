# Interface d’administration MyEMS — code technique

Ce répertoire conserve des fichiers d’administration AngularJS provenant d’une base MyEMS préexistante. Les intitulés et chemins internes nécessaires au chargement ne sont pas traduits.

L’interface est **incomplète** dans cette archive : les vues HTML sous `views/` et l’API attendue sous `/api/` sont absentes. Il ne s’agit pas d’une démonstration exécutable certifiée.
